# 卸载后的终端恢复

已加载新版片段与 hook 的 shell 会保留本 scope 的恢复函数。安装器退出账号后，即使尚未刷新过的终端错过了磁盘上的 release 片段，只要整个固定状态目录被卸载删除，下一次刷新仍可恢复这个 shell 首次接管时的原值。工具新增的变量会移除，原来存在的空值会保留，无关变量及用户对无关变量的修改不动。

恢复由 shell 自己执行。后台程序不能从外部强制修改已经运行的进程环境，也不能追回应用已经读取的明文。

## 本地生命周期合同

自动恢复必须同时满足：固定片段和固定状态目录都已不存在，二者均无残存符号链接，固定父目录仍存在、可读且可遍历。现有完整卸载会删除状态目录并保留共享父目录，符合这一合同。

单个片段缺失、现存片段不可读、状态目录仍在、状态目录残存符号链接，或者父目录不可访问，都不被推断为卸载。正常停服、崩溃、离线和暂停保留持久状态目录/片段，继续使用既有规则。暂停不重复纠正外部修改，但收到的变量释放仍恢复原值。

便携 shell 的 `test` 不能完整区分暂时文件系统错误和目录消失。本实现把“整个固定状态目录消失、固定父仍可访问”视为该本地 scope 结束；人工重命名或删除整个目录也会触发同样恢复。若卸载部分失败而目录还在，自动恢复不会把它猜作成功。

单 scope 用户还可以在已加载 hook 的本 shell 中显式运行：

```sh
harmonia_refresh --release
```

这只清理当前 shell 已记录的托管变量，不注销账号、不修改云端或磁盘。若片段仍在，后续普通刷新会重新接管；因此这个命令不是停用环境或暂停同步的替代品。

## shell 与 scope

`RenderShellHook` 为每个固定片段路径生成独立刷新函数与安装标记。bash/zsh 每次显示主提示符前刷新；重复加载同 scope 不重复挂载，既有提示钩子保留。sh 没有通用的可移植提示钩子，仅在开始加载及显式 `harmonia_refresh` 时刷新。

多个 scope 的函数、首次原值与 revision 互不覆盖，prompt 直接使用各自的固定函数，不依赖共享别名。`harmonia_refresh` 显式别名对应最后加载的 scope；sh 多 scope 的调用者须保留并调用生成脚本中各自的固定函数。不同安装同时接管同名变量的仲裁不属于此切片；正式服务仍以单 UID owner 为边界。

旧版 Bash 只执行 `PROMPT_COMMAND` 的首个数组元素。实现保留原数组，将固定 scope 命令串入首元素，并处理 `set -u` 下的空数组；Bash 5.1 及后续版本使用逐元素提示钩子。[GNU Bash 5.1 变更说明](https://lists.gnu.org/archive/html/bug-bash/2020-11/msg00089.html)、[当前交互 shell 文档](https://www.gnu.org/software/bash/manual/html_node/Interactive-Shell-Behavior.html)支持这一版本边界。

恢复函数只包含严格验证过的固定变量名及本 shell 原值引用，不包含云端值，不枚举环境，不使用 `eval`。原值文本不会被当成 shell 命令执行。每个变量恢复后立即清除其 SEEN/EXISTS/VALUE/REV 缓冲，重复刷新不会覆盖恢复后的新修改；重新接管则记录新的原值。

已运行的旧 shell 必须重新加载新版片段和 hook，才能得到这些函数；仅更新磁盘源码不能在旧进程中补出过去没有生成的恢复逻辑。本实现不自动修改用户启动文件。未知 shell、没有加载适配的非交互进程、GUI、容器、cron 及其它业务服务仍不在首版范围。

自动恢复需要该 shell 实际观察到目录消失。如果在它刷新前就以同路径快速重装，缺失窗口可能不可见；跨安装实例的持久生命周期标记不属于本切片，不能声称这个场景已恢复。重新接管回归在旧 shell 已执行一次恢复后进行。

## 合成验证

使用公开 core `c8b66ac7cc6ee8d10abc834d90ecc4d80be6d774` 的独立归档加此切片，Go 1.26.4。真实子进程执行 sh、Bash 3.2 和 zsh 5.9，环境只含明确注入的合成值；bash/zsh 的恢复场景包含真实交互主提示符。

修复前，卸载恢复的五个子场景实际全部失败；最终 `platform` 全包 race 回归 48 项主测试及子场景通过，0 失败、0 跳过。覆盖卸载错过 release、空值/新增变量恢复、恶意字面值不执行、幂等与重新接管、仅片段缺失、父目录缺失、残存符号链接、两个不重叠 scope、提示钩子保留、正常持久片段纠正及暂停/撤销。测试不读取宿主环境，不安装或卸载宿主服务。

```sh
mise exec -- go test -race ./platform -count=1
mise exec -- go vet ./platform
```

这些是 shell/provider 合成测试，不能替代 macOS 安装器的真实 VM 安装、UID 降权、PID drain、卸载与系统重启验收；Bash 5.1 后续版本的独立执行亦不在本次结果中。项目仍是实验性源码。
