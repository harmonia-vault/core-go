# 已有设备的权限管理

本模块供系统认证后的原生手机业务层调用，尚未接入 Flutter 页面或 Android MethodChannel。它复用既有 `SignedGrant` 和设备撤销签名域，不通过密码登录、服务器目录公钥或恢复受限会话获得设备信任。

## 调用顺序

1. `ManagementDevices(ctx, environmentID)` 在线拉取当前配置，再请求独立管理投影；仅当前该环境 Admin 可以查看。返回设备 ID、角色、期限、key version 和最高接受授权代际，不返回目录公钥、HPKE 封套或签包。
2. `PrepareDeviceGrant(ctx, GrantUpdateIntent)` 接受显式设备、环境、RO/RW/Admin/none 及期限选择。`ExpiresAt=0` 表示永久；none 的输入期限必须是 0，签包期限按当前管理者的期限归一，满足既有服务端规则。只有本地受签身份图中的精确 Ed25519/X25519 公钥可接收新封套。新授权始终采用当前 key version 和该设备最高接受代际加一，不能从 none、到期或旧 key version 重置代际。
3. 或调用 `PrepareOtherDeviceRevocation(ctx, id, subjectDeviceID, environmentID)`，准备其它设备的全局撤销。环境参数用于获取受签身份来源，实际撤销仍要求管理者对账号所有当前环境具有 Admin；它不能撤销自己。
4. Prepare 保存不可变原请求到原生 AES 上下文后返回 `ManagementInfo`，尚未调用写入接口。`RetryManagement(ctx, id)` 先查该设备自己的精确原 ID 回执。若尚未接受，重新验证当前权限后，在真实 POST 前持久化尝试标记；同一签包、随机封套、原 ID 与原撤销 session 绑定不变。
5. 接受回执必须匹配原签字节及签名的 SHA256。之后经完整验签的普通 Pull 收敛本机缓存，并获取可用管理投影的最新检查点；不会把目标当前角色相同视为原操作成功，也不会把旧回执再次写回覆盖后来权限。

`ManagementInfo()` 只返回进度元数据。`CancelManagement(id)` 只允许尚未到达提交屏障的原请求，并持久化退休 ID；已经尝试但结果未知的请求不能取消或隐式生成替代 ID。确切接受后因 Pull 或原生保存失败未收敛时，保留接受序号，返回 accepted-not-applied。保存错误不能假报已持久完成。

## 保护与限制

每个原生上下文仅允许一个管理待处理请求。待处理期间普通查看、变量/环境操作以及新审批被相应入口门控；允许查询原事务和显式退出账号。管理和普通共享写入在暂停、离线、未确认入网或受限恢复时拒绝执行；已接受的服务器回执与未知网络结果分别表示。

管理投影的候选公钥必须与完整、已固定的根/双签入网身份图匹配；none 只独立验签，不是权限图中的可授予权限节点。受保护状态保留已见最高代际及精确签包指纹；服务器返回 `null/GG0` 不能清除已见下界。暂无密码学缺席证明，服务器仍须在接受事务中检查精确当前代际及角色。

临时 Admin 不能签更长或永久授权。其它设备撤销包额外绑定一次性挑战、全环境授权和原 session hash；原随机 bearer 最多保留原 120 秒交易所需期间。检测到期限后清原 bearer，新 boot 会话只能查询原 ID 的精确接受回执，不能改绑原签包后再次提交。未知结果即使已经到期仍保持待处理；显式退出账号清待处理、历史下界及进程中的原生材料。

原生保护上下文总计仍限制 8 MiB，单个管理原签交易不超过 2 MiB；最多保存 256 个已完成/取消 ID、256 个环境目录及 4096 个设备授权下界，超过上限明确拒绝，不静默删除退休 ID。此限制需要后续设计安全压缩机制。上下文可以包含加密封套、历史来源及短时随机会话，但不包含设备私钥、密码派生凭据、恢复种子；禁止交 Dart、日志或明文文件。

## 验证证据

`syncclient/grant_updates_test.go` 和 `mobileworkflow/management_test.go` 覆盖原包逐字节恢复、504 接受响应丢失时不乐观应用、回执 hash 错误、持久化屏障失败禁止 POST、tuple/epoch/签名/目录公钥/代际负例、非法角色和期限、暂停及受限恢复门控。

workspace 的 `acceptance/management_test.go` 使用真实 HTTPS → TypeScript → SQLite、真实初始化和固定 BoringSSL 双向 SPAKE2 接受设备；覆盖已有设备 RO/RW/Admin/none、期限上限、已见代际、防目录公钥替换、native AES 丢响应重启、旧回执不覆盖后来权限、到期旧 key version 重新授权，以及其它设备全局撤销和旧设备会话/boot 拒绝。默认未启用原生构建时明确跳过这一项，不能视为通过。

本模块是实验性安全实现，不宣称生产可用；Android 系统认证、真实手机页面管理闭环以及 Windows 原生后台服务没有由这些 Go 合成测试证明。
